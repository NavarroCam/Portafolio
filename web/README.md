# 🎨 Portfolio Web - Camila Navarro

Portfolio personal desarrollado con HTML, CSS y JavaScript vanilla.

🌐 **Sitio en vivo:** https://portafolio-jade-five-33.vercel.app/

## ✨ Características

- 📱 **Responsive**: menú hamburguesa en móvil y layouts que se adaptan a cualquier pantalla
- 🌙 **Modo oscuro**: sigue la preferencia del sistema y recuerda la elección, sin parpadeo al cargar
- 📄 **CV descargable** en PDF
- 🧭 **Navegación** con resaltado de la sección activa y scroll suave
- ♿ **Accesible**: navegación por teclado, enlace "Saltar al contenido", contraste AA y soporte de `prefers-reduced-motion`
- 🔗 **Vista previa al compartir** (Open Graph) en LinkedIn y WhatsApp

## 🚀 Secciones

- **Inicio**: presentación, CV y redes
- **Sobre mí**: perfil profesional
- **Experiencia**: pasantía de IT y experiencia previa
- **Formación**: carrera, diplomatura en Testing QA y automatización
- **Habilidades**: agrupadas por testing, lenguajes, bases de datos y herramientas
- **Proyectos**: tarjetas con captura, tecnologías y enlace al código
- **Contacto**: email, LinkedIn, GitHub y teléfono

## 📦 Tecnologías

- HTML5 semántico
- CSS3 (Grid, Flexbox, variables CSS)
- JavaScript vanilla (IntersectionObserver)
- Google Fonts (Montserrat)
